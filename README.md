A program (Node 22, no dependencies) that writes one funny line of text to
`/output/entry.txt`.

## The line

> My car beeps when I forget my seatbelt, but stays silent about every bad decision I've ever made.

97 characters, 97 bytes, no trailing newline.

Why this line: the laugh lands inside the line with no setup the reader
has to supply — a car that beeps about a forgotten seatbelt, and then the
twist: the same car stays silent about every bad decision the driver has
ever made. The contrast between a machine that polices a small safety rule
and ignores a lifetime of poor choices is unexpected, the wording is plain
and sounds like a person talking, and the line still amuses on a second
read and is easy to repeat. The humour is self-deprecation aimed at the
speaker, never at anyone else.

## Run

```sh
node main.ts
```

The output is deterministic: two runs write byte-identical files.
